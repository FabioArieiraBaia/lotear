# Lotear - Sistema de Gestão de Loteamentos

Sistema completo para gerenciamento de loteamentos, lotes, corretores e compradores.

**Desenvolvido por:** Fabio Arieira - Full Stack Developer

## Funcionalidades

- Gerenciamento de loteamentos e lotes
- Mapa interativo com Leaflet
- Cadastro de corretores e compradores
- Dashboard administrativo
- Integração com IA Gemini para assistência

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`

2. Configure o arquivo `.env.local` com sua chave de API do Gemini:
   `GEMINI_API_KEY=sua_chave_aqui`

3. Run the app:
   `npm run dev`

4. Acesse: `http://localhost:5173`

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- Leaflet (mapas interativos)
- SQLite
- Firebase
- Gemini AI API
